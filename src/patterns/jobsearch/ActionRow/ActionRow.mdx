# ActionRow

**One next action in the Today list.** A done ring, the title, company and stage chips, the time, the due label, a Snooze split button and an Open button. The first of the Job Search HQ patterns: it composes `Button`, `Chip` and `Menu`, and nothing in it is a new primitive.

## The ring is a Button, not a Checkbox

Done is a **one-way action with an Undo**. A checkbox promises a toggle; this ring does not toggle back — Undo lives in the list's toast (and in the list). So it is `<button aria-label="Mark done: Email Priya" aria-pressed>`: the state is exposed, the action is one-way.

## Who owns what

| The row | The list (Today, Phase 4) |
| --- | --- |
| its four controls, named for the action | J/K between rows, D/S/O for the current row |
| the done moment (ring, tick, strike, collapse) | flipping `isDone` at once, and back on Undo |
| `:focus-within` outline | the one Undo toast, the live region "Done. 3 due today." |
| nothing formatted — `dueLabel` and `time` are strings | relative dates, locale, groups and counts |

Letter shortcuts are deliberately **not** on the row: a key listener on a row fires inside quick-add's input when focus is within it, and the list already knows which row is current.

## The done moment

Press → ring scales to 0.9 → ring fills and the tick draws → the title turns subtle and a strike grows left to right → the row collapses (`grid-template-rows: 1fr → 0fr`, the only layout animation allowed) → the list shows the toast. Every duration is a token, so under `prefers-reduced-motion` it all lands at once. Undo mid-animation reverses from wherever it is.
