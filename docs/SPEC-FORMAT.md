# Component spec format (`*.spec.json`)

Every component ships a machine-readable spec next to its source. The MCP server serves them (`get_spec`, `search_components`, `find_by_a11y_role`, `find_by_token`, `find_by_compose`). `npm run check:specs` validates every spec against `spec.schema.json` and against the real TypeScript props, so a spec can't drift from the code.

The spec is written **before** the code. It is the design-review artefact.

## Shape

```jsonc
{
  "name": "Button",
  "category": "Actions",                // one of the eight categories
  "status": "draft | beta | stable | deprecated",
  "since": "0.1.0",
  "summary": "One sentence: what it is for and when NOT to use it.",
  "pattern": {                          // APG pattern it implements
    "name": "Button",
    "url": "https://www.w3.org/WAI/ARIA/apg/patterns/button/"
  },
  "role": "button",                     // primary ARIA role
  "props": {
    "variant": {
      "type": "'primary' | 'secondary' | 'tertiary' | 'ghost' | 'danger'",
      "default": "'secondary'",
      "intent": "Visual weight. One primary per view."
    },
    "size": { "type": "'sm' | 'md' | 'lg'", "default": "'md'", "intent": "lg is the touch default (44px target)." },
    "isDisabled": { "type": "boolean", "default": "false", "intent": "Prefer leaving enabled + validation message; disabled controls are not focusable and not explained." },
    "isPending": { "type": "boolean", "default": "false", "intent": "Shows progress, keeps focus, announces 'busy' via aria-busy." },
    "iconStart": { "type": "ReactNode", "intent": "Decorative; aria-hidden applied automatically." },
    "aria-label": { "type": "string", "requiredWhen": "children is empty (icon-only)", "intent": "The accessible name." },
    "onPress": { "type": "(e: PressEvent) => void", "intent": "Fires for mouse, touch, keyboard and screen reader activation alike." }
  },
  "states": ["default", "hover", "focus", "active", "disabled", "pending"],
  "keyboard": [
    { "key": "Tab", "action": "Moves focus to the button." },
    { "key": "Enter", "action": "Activates." },
    { "key": "Space", "action": "Activates (on key up)." }
  ],
  "a11y": {
    "wcag": ["2.1.1", "2.4.7", "2.4.11", "2.4.13", "2.5.8", "4.1.2"],
    "name": "From children, or aria-label when icon-only (required by type).",
    "announcements": "isPending → aria-busy=true; the label stays, a visually-hidden 'loading' is appended.",
    "screenReaderNotes": "VoiceOver/Safari 2026-xx: ok. NVDA/Firefox: ok.",
    "targetSize": "min 24×24 (sm), 32 (md), 44 (lg)"
  },
  "tokens": [
    "color.action.primary.bg", "color.action.primary.bg.hover", "color.action.primary.bg.active",
    "color.text.on-action", "color.border.focus", "space.inset.md", "radius.md",
    "size.target.min", "duration.fast"
  ],
  "compose": [],                        // system components this one is built from
  "composedBy": ["Modal", "Toast", "FormPage"],   // generated by check:specs
  "rules": [                            // load-bearing rules not obvious from source
    "Never use a Button for navigation — use Link (role matters to screen readers).",
    "Never disable the submit button to signal invalid form; validate and explain instead.",
    "Icon-only buttons must have aria-label; the TypeScript union enforces it."
  ],
  "figma": {
    "componentSet": "Actions / Button",
    "properties": { "Variant": "variant", "Size": "size", "State": "states", "Icon start": "iconStart" }
  },
  "examples": [
    { "title": "Primary action", "code": "<Button variant=\"primary\" onPress={save}>Save</Button>" },
    { "title": "Icon only", "code": "<IconButton aria-label=\"Close\"><CloseIcon /></IconButton>" }
  ]
}
```

## Page template specs

Templates (`category: "Template"`) add `"template": { "file": "templates/TablePage.tsx", "slots": [...] }` and the MCP `get_template` returns the paste-ready JSX. Templates use only public exports.

## Validation rules (`check:specs`)

- Every prop in the TypeScript `NameProps` appears in `props`, and vice versa (except `className`, `style`, `ref`, `children` which are implicit).
- `tokens` must all exist in `tokens.dtcg.json`; every `var(--iz-*)` used in the component's CSS must be listed.
- `keyboard` is non-empty for any component with `role` other than `presentation`/`none`.
- `states` includes `focus` for any interactive component.
- `status: stable` requires a non-empty `a11y.screenReaderNotes`.
- `composedBy` is regenerated, never hand-edited.

## MCP tools backed by specs

| Tool | Reads |
|---|---|
| `list_components({category?})` | name, category, status, summary |
| `get_spec({name})` | full spec |
| `search_components({query})` | summary, rules, props.intent |
| `find_by_a11y_role({role})` | `role` |
| `find_by_token({token})` | `tokens` |
| `find_by_compose({name})` | `compose` / `composedBy` |
| `list_tokens({category?, query?})` | `tokens.dtcg.json` with values per theme |
| `list_templates()` / `get_template({name})` | template specs |
| `get_changes({since})` | changesets |
